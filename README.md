## 📖 项目简介

《绒华物语》是一个以南京绒花为核心的静态科普网站，共设六个页面，从历史、工艺、传承、作品四个维度全方位呈现这项国家级非物质文化遗产。整体采用酒红配米白的国风配色，配合历代名画配图、工艺实拍与可放大的作品细节，让用户在一丝一线之间读懂千年荣华。

## ✨ 功能特性

- **首页无缝轮播**：三图循环轮播，支持自动播放、左右箭头与圆点跳转，克隆首尾实现无缝过渡
- **发展历史时间轴**：秦汉至近现代的横向滑动时间轴，节点配历代名画，点击可放大并滚轮缩放查看
- **自定义视频播放器**：纯 JS 实现播放/暂停、进度拖拽、音量调节、全屏等完整控制（无浏览器原生控件）
- **九步工艺轮播**：炼丝→染色→晾晒→劈绒→勾条→打尖→传花→整型→装配，分步图解，勾条/传花附详情弹窗
- **作品分类筛选**：45 件作品按头饰、配饰、摆件、现代设计四类即时筛选，点击放大查看大图
- **传承人介绍**：赵树宪、蔡志伟、刘梅/征珊珊三代传承人的个人卡片
- **留言板系统**：表单校验、localStorage 本地持久化、XSS 转义防护、邮箱隐私脱敏
- **响应式布局**：适配桌面端与移动端，导航菜单在小屏下折叠

## 🛠 技术栈

- **前端：** 原生 HTML5 / CSS3 / JavaScript（ES6）
- **框架：** 无，纯手写
- **构建工具：** 无，零依赖
- **数据存储：** localStorage（留言板持久化）
- **交互实现：** DOM API 驱动轮播、模态框、视频控制、分类筛选、时间轴滑动
- **部署：** GitHub Pages（静态托管）

## 🚀 快速开始

### 环境要求

- 无任何依赖，任意浏览器即可

### 安装运行

```bash
# 克隆仓库
git clone https://github.com/你的用户名/ronghua-story-website.git

# 进入目录
cd ronghua-story-website

# 方式一：直接双击 index.html 打开
# 方式二：启动本地服务器（推荐，资源路径更稳定）
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## ❓ 常见问题

**Q1：双击 index.html 打开时部分图片不显示？**
A：部分图片使用相对路径引用，直接双击时可能因路径根目录差异而丢失。建议使用 `python -m http.server` 启动本地服务器访问，或部署到 GitHub Pages 后在线浏览。

**Q3：工艺视频无法播放？**
A：视频为 mp4 格式，请使用 Chrome / Edge / Firefox 等现代浏览器；若网络不佳可稍等缓冲，页面已提供原视频的 B 站链接。
